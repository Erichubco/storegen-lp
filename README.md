# Boutik — SaaS "Clone & Rebrand" Shopify

Outil qui construit une boutique Shopify française complète à partir de l'URL d'un produit gagnant (US, Allemagne, France).

## État
- ✅ Landing page prototype (`index.html`)
- ⏳ Backend OAuth Shopify
- ⏳ Pipeline IA (Claude + Gemini)
- ⏳ Thème master Dawn customisé

## Stack cible
Next.js + Postgres + Inngest + Claude API + Gemini + Stripe + Shopify Admin API

## Quick start
```bash
open index.html  # ouvre la LP dans le navigateur
```
